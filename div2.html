Html

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It acts as the skeleton or blueprint of every website on the internet, dictating how text, images, links, and multimedia are organized and displayed by web browsers.

CSS

CSS Cascading Style Sheets (CSS) is a cornerstone stylesheet language used to control the presentation, formatting, and layout of documents written in a markup language like HTML or XML. While HTML provides the structural foundation of a web page, CSS determines its visual appearance—including colors, fonts, spacing, and layouts.

Javascript

Javascript is a highly popular, open-source online textbook and tutorial platform dedicated to teaching modern JavaScript from the ground up. Created by Ilya Kantor in 2007, the project spans roughly 1,300 pages and is maintained as a community-driven repository on GitHub.

Python

Python is a high-level, interpreted, general-purpose programming language known for its clear syntax, code readability, and versatility. Created by Guido van Rossum and first released in 1991, it has become one of the most popular languages in the world, powering fields from web development to artificial intelligence.
